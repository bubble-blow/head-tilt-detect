# 坐姿检测软件（PyQt + MediaPipe）

一个基于 Windows 前置摄像头的实时坐姿检测桌面程序：
- 使用 MediaPipe Face Mesh 提取双眼外眼角关键点
- 计算双眼连线相对水平线的角度
- 在美观的 PyQt 界面中显示实时视频、姿态状态与角度提示

## 功能说明

- **实时检测**：调用摄像头并实时显示画面。
- **水平判断**：当双眼连线角度绝对值小于阈值（默认 6°）时，判断为姿态良好。
- **状态提示**：通过颜色卡片文字提示“坐姿良好 / 请调整姿势”。
- **阈值可调**：支持 2°~15° 的阈值滑块，适配不同使用习惯。

## 环境要求

- Windows 10 / 11
- Python 3.10+
- 可用前置摄像头

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python app.py
```

## 关键算法

1. 使用 `FaceMesh` 检测人脸关键点。
2. 获取左右外眼角点（索引 `33` 与 `263`）。
3. 角度计算：
   
   `angle = degrees(atan2(y_right - y_left, x_right - x_left))`
4. 当 `abs(angle) <= threshold` 判定为“头部基本水平”。

## 注意事项

- 首次运行需允许系统摄像头权限。
- 若摄像头占用或权限被禁用，会提示无法打开摄像头。
- 如需打包成 exe，可进一步使用 `pyinstaller`。
